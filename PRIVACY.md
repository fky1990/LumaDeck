# Privacy Policy

Effective date: July 19, 2026

LumaDeck is a local macOS utility. The application does not collect, store, sell, or transmit personal data.

## Data processed locally

LumaDeck reads display information supplied by macOS, including display identifiers, names, supported modes, active state, and brightness capability. This information is used only to render the interface and apply the display actions requested by the user.

The application stores a small number of preferences locally, including displays disabled by LumaDeck and login-item state. These preferences remain on the Mac and are not transmitted.

## Network access

LumaDeck does not require network access and contains no analytics, advertising, crash-reporting, or tracking SDK.

## Permissions

The current version does not request Accessibility, Screen Recording, camera, microphone, contacts, location, or notification permissions.

## Third parties

LumaDeck does not share information with third parties.

## Changes

Material changes to this policy will be documented in the repository and release notes.

## Contact

For privacy questions, open a private security advisory in the GitHub repository or contact the repository maintainer through their GitHub profile.
