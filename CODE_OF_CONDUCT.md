# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of experience, identity, background, or ability.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on ideas and code, not people.
- Welcome questions and different experience levels.
- Respect privacy and avoid publishing personal or device-identifying information.
- Accept maintainers' decisions about project scope and safety.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing another person's private information without permission.
- Deliberately unsafe advice or changes that can leave users without a visible display.
- Repeated disruption of project discussions or review.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this code. Serious or sensitive incidents should be reported privately through a GitHub security advisory or the maintainer's GitHub profile rather than a public issue.

## Scope

This code applies to repository discussions, issues, pull requests, releases, and other spaces where someone represents the LumaDeck project.
