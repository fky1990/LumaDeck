# Support

Use GitHub Issues for reproducible bugs and feature requests. Select the matching issue form and provide the requested hardware and macOS details.

Before opening an issue:

1. Confirm you are running the newest release.
2. Reconnect the affected display and refresh LumaDeck.
3. Check [README.md](README.md) and [docs/PRIVATE_APIS.md](docs/PRIVATE_APIS.md).
4. Search existing issues for the monitor model or symptom.

Security-sensitive problems must be reported privately as described in [SECURITY.md](SECURITY.md).
